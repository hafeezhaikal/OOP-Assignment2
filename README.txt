    Ticket.java          - abstract base class (was TicketSystem in Assignment 1)
    StandardTicket.java  - derived class 1
    VIPTicket.java       - derived class 2
    EarlyBirdTicket.java - derived class 3
    Customer.java        - additional class 1
    Event.java           - additional class 2
    BookingManager.java  - additional class 3
    Main.java            - main class (Part 1 demo + Part 2 interactive menu)
